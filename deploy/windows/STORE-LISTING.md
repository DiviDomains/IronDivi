## 2. Descriptions

### Short Description (up to 100 characters)
Fast, secure Rust implementation of the Divi cryptocurrency full node and non-custodial wallet.

### Full Description (Rich Text / Markdown)
IronDivi is a modern, high-performance implementation of the Divi cryptocurrency full node and wallet, engineered from the ground up in memory-safe Rust.

Designed for security, speed, and ease of use, IronDivi allows anyone to run a sovereign full node, validate transactions independently, stake DIVI coins with Proof-of-Stake (PoS), and manage their assets through a sleek, built-in Web UI dashboard.

### Key Highlights:
- **Rust Memory Safety**: Built completely in Rust, eliminating whole classes of memory corruption vulnerabilities and providing maximum network resilience.
- **Embedded Web UI Dashboard**: Automatically launches a modern, responsive web dashboard in your browser with real-time sync telemetry, staking statistics, peer visualization, and wallet controls.
- **Full Node Validation**: Synchronizes and validates the complete Divi blockchain ledger independently with zero reliance on centralized third parties.
- **Proof-of-Stake (PoS) Staking**: Stake DIVI directly from your Windows desktop with lightweight resource consumption.
- **Non-Custodial HD Wallet**: Hierarchical Deterministic (BIP39/BIP32) wallet support. Your private keys remain encrypted locally on your computer—you maintain 100% control of your assets.
- **Masternode Integration**: Inspect, configure, and monitor Copper through Diamond tier masternodes.
- **Developer & Power User CLI**: Includes `irondivi-cli` registered directly into Windows PowerShell and Command Prompt for automated scripting and RPC control.
- **Cross-Chain Atomic Swaps**: Built-in support for decentralized peer-to-peer atomic swaps.
