What this is (testnet)

This is a swap maker for DIVI. It trades DIVI test coins directly against other test coins (Bitcoin, Litecoin, Zcash and Monero test networks) with no exchange in the middle. Each swap is an atomic swap: either both sides complete or both sides get their coins back.

How to swap (testnet)

  1. Get test coins from the faucet: https://services.divi.domains/testnet/faucet
  2. Get the divi-swap taker app. The taker app is not published yet, so there is no download link on this page.
  3. Pick an offer id from the table above and run, on the test networks (the default profile):
divi-swap --maker https://divi.cx/swap quote --offer OFFER_ID --btc-sats AMOUNT
divi-swap --maker https://divi.cx/swap run   --offer OFFER_ID --btc-sats AMOUNT

AMOUNT is the counter-coin amount in satoshis (1 coin = 100,000,000). quote only prints a price. run does the whole swap. Add --counter-chain ltc or zec for offers on those coins. Other steps, if you want them one at a time: accept, lock, status, claim, refund.
