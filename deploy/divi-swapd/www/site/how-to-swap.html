How to swap (testnet)

1. Get test coins

Test coins are free. Get DIVI test coins from the faucet: services.divi.domains/testnet/faucet. For the other coin you need test coins on that chain too (Bitcoin signet, Litecoin testnet, Zcash testnet or Monero stagenet).

2. Get the taker app

The taker app (divi-swap) is not published yet. There is no download link on this site because there is nothing to link to. When it is published, the link will be added here.

3. Pick an offer

Open the Home page and note an offer id, for example divi-ltc-testnet. The offer says which coin you pay and which you get, and the smallest and largest swap.

4. Run the swap

The amount is given in the other coin, in its smallest unit (1 coin = 100,000,000 units). To see a price without committing to anything:

divi-swap quote --maker https://divi.cx/swap --offer OFFER_ID --btc-sats AMOUNT

For an offer on Litecoin, Zcash, Monero or USDC add --counter-chain ltc (or zec, xmr, usdc) as well. The command needs your own test keys, given as --divi-key and the key flag for the other coin; run divi-swap --help for the full list. The default network settings are the test networks.

To do the whole swap in one command:

divi-swap run --maker https://divi.cx/swap --offer OFFER_ID --btc-sats AMOUNT

Or one step at a time:

  1. quote – prints a fresh price. Quotes expire after 60 seconds.
  2. accept --maker … --offer … --btc-sats … – takes a new quote and accepts it. It prints a swap id.
  3. lock --swap SWAP_ID – puts your coins into the swap lock and tells the maker.
  4. status --swap SWAP_ID – shows what the maker sees.
  5. claim --swap SWAP_ID – once the maker has locked its side and it is confirmed, collects your new coins.
  6. refund --swap SWAP_ID – if the swap stalls, takes your own coins back once the waiting time has passed. See how it works and safety.

run does all of this for you and picks between claim and refund by itself.

The commands above are taken from the divi-swap command-line source. Nothing here is a real-money instruction: the default is the test networks, and mainnet needs an explicit extra flag that this site does not describe.
