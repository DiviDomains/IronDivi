listlockunspent

Returns list of temporarily unspendable outputs.
See the lockunspent call to lock and unlock transactions for spending.

Result:
[
  {
    "txid" : "transactionid",     (string) The transaction id locked
    "vout" : n                      (numeric) The vout value
  }
  ,...
]

Examples:

List the unspent transactions
> divi-cli listunspent 

Lock an unspent transaction
> divi-cli lockunspent false "[{\"txid\":\"hash\",\"vout\":1}]"

List the locked transactions
> divi-cli listlockunspent 

Unlock the transaction again
> divi-cli lockunspent true "[{\"txid\":\"hash\",\"vout\":1}]"

As a json rpc call
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "listlockunspent", "params": [] }' -H 'content-type: text/plain;' http://127.0.0.1:51473/
