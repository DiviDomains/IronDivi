dumpprivkey "diviaddress"

Reveals the private key corresponding to 'diviaddress'.
Then the importprivkey can be used with this output

Arguments:
1. "diviaddress"   (string, required) The divi address for the private key

Result:
"key"                (string) The private key

Examples:
> divi-cli dumpprivkey "myaddress"
> divi-cli importprivkey "mykey"
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "dumpprivkey", "params": ["myaddress"] }' -H 'content-type: text/plain;' http://127.0.0.1:51473/
