sendtoaddress "diviaddress" amount (feeMode|metadata)( "comment" "comment-to" )

Send an amount to a given address. The amount is a real and is rounded to the nearest 0.00000001

Arguments:
1. "diviaddress"  (string, required) The divi address to send to.
2. "amount"      (numeric, required) The amount in DIVI to send. eg 0.1
3. "comment"     (string, optional) A comment used to store what the transaction is for. 
                             This is not part of the transaction, just kept in your wallet.
4. "comment-to"  (string, optional) A comment to store the name of the person or organization 
                             to which you're sending the transaction. This is not part of the 
                             transaction, just kept in your wallet.

Result:
"transactionid"  (string) The transaction id.

Examples:
> divi-cli sendtoaddress "diviaddress" 0.1
> divi-cli sendtoaddress "diviaddress" 0.1 "donation" "seans outpost"
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "sendtoaddress", "params": ["diviaddress", 0.1, "donation", "seans outpost"] }' -H 'content-type: text/plain;' http://127.0.0.1:51473/
