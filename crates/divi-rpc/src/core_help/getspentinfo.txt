getspentinfo {txid:,index:}

Returns the txid and index where an output is spent.

Arguments:
{
  "txid" (string) The hex string of the txid
  "index" (number) The start block height
}

Result:
{
  "txid"  (string) The transaction id
  "index"  (number) The spending input index
  ,...
}

Examples:
> divi-cli getspentinfo '{"txid": "hash", "index": 0}'
> curl --user myusername --data-binary '{"jsonrpc": "1.0", "id":"curltest", "method": "getspentinfo", "params": [{"txid": "hash", "index": 0}] }' -H 'content-type: text/plain;' http://127.0.0.1:51473/
